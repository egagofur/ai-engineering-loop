# Dig first, then ask: sources and provenance (C-45, C-46)

Source: brainstorm 2026-11-21 after poteto's live (agents that look things up in Slack/Linear before asking). Decisions agreed with the maintainer:

- External connectors are **read-only triggers** (first: Mattermost through the Mattermost-Agent MCP read tools). Without them the agent still digs in code, git, `gh`/`glab` and AEL history.
- Every statement in the Goal Contract and the grill is labelled **fact / decision / assumption**. A fact needs a source the CLI can check; otherwise it is downgraded to assumption.
- Unconfirmed assumptions are **shown, never blocking**, on every tier.
- No new GUI: Studio and receipts show sources.

## C-45 · P1 · `sources.md` registry and a per-tier gather budget

**Now:** agents either ask the human what the repo, the tracker or the chat already answers, or dig without limit (token brute force).

**Change:**
1. `init` and `refresh` write `.ai-engineering-loop/sources.md`: which sources exist on this machine (git, `gh auth status`, `glab auth status`, Mattermost-Agent MCP found in a host config, AEL history: lessons, debt, past Runs) and their scope. The human edits scope (channels, labels); the CLI never stores tokens.
2. Gather budget per tier: T0 0 queries, T1 at most 4, T2 at most 8. Stop early once every Goal Contract statement has a source.
3. Results are cached compactly in `runs/<id>/sources.json`: `{ source, ref (link, file:line, commit), line }`, one line each, redacted.
4. Token use is recorded with `budget record --role gather`.
5. `ael sources hint` prints the commands and MCP read tools worth trying for this goal (the agent runs them; the CLI verifies).

**AC:**
- `init` on a repo with `gh` logged in lists GitHub as a source; on a machine without it, the file says so and nothing fails.
- A T1 Run that records a fifth gather query is refused with why/fix naming the budget.
- `sources.json` never stores tokens or home paths (`audit:package` stays green).
- No connector write tool is ever named in `sources.md` or the hint.

**Effort:** M.

## C-46 · P1 · Provenance labels: fact, decision, assumption

**Now:** the Goal Contract mixes what was read, what the human decided and what the agent guessed; reviewers cannot tell which is which.

**Change:**
1. Goal Contract statements carry `kind: fact | decision | assumption` and, for a fact, `source` (`path:line`, commit SHA, URL or a `sources.json` id).
2. The goal gate checks each fact's source: the file and line exist, the commit exists (`git cat-file`), the URL is one recorded in `sources.json`. A fact that fails is downgraded to assumption and the downgrade is logged; the gate does not fail.
3. A decision names who decided (`--by`) or a recorded source.
4. Assumptions are listed in `status`, the receipt and Studio under "Unconfirmed"; they never block delivery on any tier.
5. Devil's Advocate gets the list and may raise a finding when code relies on an unconfirmed assumption.

**AC:**
- A fact citing `src/a.js:999` on a 10-line file shows as assumption with the reason.
- A fact citing an existing commit stays a fact.
- A Run with three assumptions delivers normally, and the receipt lists them.
- Prose cannot promote an assumption to a fact: only a checkable source does.

**Effort:** M.
